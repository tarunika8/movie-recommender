 Movie Recommender System

 LIVE APP LINK :https://movie-recommender-styrqlzaw8zz9agkt7mt3e.streamlit.app/

A content-based movie recommendation system built using:
- Python
- Pandas
- Scikit-learn
- Streamlit
- TMDB API

Features
- Recommends top 5 similar movies
- Displays movie posters
- Interactive web interface

How It Works
- Text features are vectorized
- Cosine similarity is computed
- Most similar movies are recommended
